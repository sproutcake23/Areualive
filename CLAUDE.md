## How this file relates to AGENTS.md

`AGENTS.md` (imported above) is the **authoritative spec** for the Datalake Biometric module: role, tech stack, target architecture, the camera↔model bridge contract, data model, and all coding rules. Read and follow it strictly.

This section adds what AGENTS.md does not: **the current state of the repo** and how spec diverges from reality, so you don't assume files/libraries exist that don't.

## Current state — fresh Expo boilerplate, not yet built out

The repo is at day-zero. `app/index.tsx` renders a placeholder; `app/_layout.tsx` is a bare `<Stack />`. The architecture in AGENTS.md (`components/`, `constants/`, `hooks/`, `lib/`, `store/`, `tasks/`, `types/`) **does not exist yet** — those directories are the target you build toward, not existing code.

**None of the core spec libraries are installed.** Before using any of these you must `npx expo install` them first (and ask, per AGENTS.md): `nativewind`, `zustand`, `react-native-mmkv`, `react-native-vision-camera`, `expo-sqlite`, `@react-native-community/netinfo`, `expo-background-fetch`, `expo-task-manager`, `expo-crypto`.

## Spec vs. actual config (verify before relying on AGENTS.md statements)

- **Expo SDK 54** is installed (`expo ~54.0.34`), not "SDK 51+" — newer than the spec assumes.
- **New Architecture is enabled** (`app.json` → `newArchEnabled: true`). Hermes is the default engine under new arch, but `jsEngine: "hermes"` is **not** explicitly set in `app.json` — AGENTS.md asks you to verify Hermes; add the key if a build check requires it.
- **React Compiler is on** (`app.json` → `experiments.reactCompiler: true`) — avoid manual memoization patterns it would make redundant.
- **Reanimated is v4** (`~4.1.1`), not v3 as the spec says. `react-native-worklets` (0.5.1) is already a dependency (worklets were split out of Reanimated v4).
- **NativeWind is not installed** — there is no Tailwind/`global.css`/`metro.config.js` setup yet, despite the styling rules assuming it.
- Path alias `@/*` maps to the repo root (`tsconfig.json`), and `typedRoutes` is enabled — use typed Expo Router routes.

## Commands

```bash
npm install                       # install JS deps
npx expo install <pkg>            # add native-aware deps (use this, not npm install <pkg>)
npm run android                   # expo run:android — builds + installs the dev client on a connected device
npm run ios                       # expo run:ios
npm start                         # expo start (dev server; needs a Dev Client build, not Expo Go)
npm run web                       # expo start --web
npm run lint                      # expo lint (ESLint flat config, eslint-config-expo)
npx tsc --noEmit                  # type-check (strict mode)
```

- **Dev Client required, not Expo Go** — native modules in the spec demand a custom build. See README for the full Android device + ADB setup (`adb devices`, enable USB debugging).
- **`/android` and `/ios` are gitignored** (generated by prebuild). They appear locally after `npx expo run:*`; never commit them.
- **No test runner is configured.** There is no `npm test`. The `reset-project` script is referenced in `package.json` but `scripts/reset-project.js` does not exist.
